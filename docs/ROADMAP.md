# Roadmap

## Marco 0: Repositorio limpo

- [x] Preservar prototipo original em `legacy/`.
- [x] Documentar diagnostico e nova filosofia.
- [x] Criar plano inicial para GitHub.

## Marco 1: MVP redesenhado

Objetivo: substituir a sensacao de lista imensa por uma primeira experiencia divertida em ate 5 minutos.

- [x] Criar `src/` com app separado em HTML, CSS e JS.
- [x] Reaproveitar o braco visual como componente central.
- [x] Criar tela inicial direto no modo Playground.
- [x] Reduzir controles visiveis: tom, camada, regiao, tocar/parar.
- [x] Adicionar botoes grandes de graus harmonicos.
- [x] Criar progressoes guiadas iniciais.
- [x] Substituir auto treino global por fluxo randomico configuravel.
- [x] Adicionar exemplos de musicas reais por familia de progressao.

## Marco 2: Missoes

Objetivo: transformar estudo em desafios curtos.

- [ ] Criar modelo de dados para missoes.
- [ ] Adicionar primeira trilha: `Casa, Tensao, Volta`.
- [ ] Criar feedback visual de acerto/erro.
- [ ] Criar progresso local por missao.
- [ ] Adicionar modo "ouvir primeiro, ver depois".

## Marco 3: Braco inteligente

Objetivo: deixar a visualizacao musicalmente confiavel.

- [ ] Iluminar posicao real no braco, nao apenas classe de nota.
- [ ] Adicionar escolha de regiao do braco.
- [ ] Mostrar graus dentro do acorde.
- [ ] Mostrar proxima nota sugerida.
- [ ] Criar modo sem nome de nota para memorizacao.

## Marco 4: Conversor musical

Objetivo: aceitar progressoes reais sem prometer mais do que entende.

- [ ] Parser para graus com alteracoes: `bVII`, `bVI`, `#iv`.
- [ ] Suporte inicial a tonalidade menor.
- [ ] Avisar tokens ignorados.
- [ ] Separar acordes diatonicos, emprestados e cromaticos.
- [ ] Permitir salvar loops favoritos.

## Marco 5: Pratica com groove

Objetivo: fazer o app soar menos mecanico.

- [ ] Click musical mais discreto.
- [ ] Groove simples de bateria ou pulso.
- [ ] Drone da tonica opcional.
- [ ] Pad harmonico simples.
- [ ] Controle de subdivisao.

## Marco 6: Publicacao

- [ ] Criar repositorio no GitHub.
- [ ] Definir licenca.
- [ ] Publicar GitHub Pages.
- [ ] Criar issues a partir do backlog.
- [ ] Escrever README com screenshots.
